# Development Guide

## Prerequisites

- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher
- **VS Code**: 1.75.0 or higher
- **Git**: Git for Windows 2.36+

---

## Setup & Compilation

1. Clone or open the repository:
   ```cmd
   cd "e:\SIDE PROJECT\githupe_acount_swicher"
   ```
2. Install dependencies:
   ```cmd
   npm install
   ```
3. Compile TypeScript code:
   ```cmd
   npm run compile
   ```
4. Watch mode for active development:
   ```cmd
   npm run watch
   ```

---

## Debugging in VS Code

1. Press `F5` in VS Code to launch the Extension Development Host window.
2. Open any Git repository in the new window to test extension activation, status bar, and account switching commands.
