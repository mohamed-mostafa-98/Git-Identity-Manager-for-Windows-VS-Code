# Client presentation

Ten browser slides explain the problem, product, installation, daily use, AI approvals, release history, limitations and a two-project pilot.

`client-walkthrough.pdf` is the ready-to-share ten-page export. Regenerate it with the presentation's Print / Save PDF button after editing slides; use landscape paper and disable browser headers/footers.

Open `index.html` directly, or visit `/presentation/` on the product website. Use Previous/Next or arrow keys; scrolling also works. Print / Save PDF creates a page per slide. The source shares the website stylesheet; the site build copies the deck into the published output.

Suggested session: explain slides 1–3, install and demonstrate slides 4–7 in VS Code, then agree on a two-project pilot using slides 8–10. Describe future functionality as planned, not delivered. Never include real tokens or connection keys in a demo.
